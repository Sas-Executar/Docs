# Schemas

Schemas de controle e interoperabilidade do ecossistema.

## Registrados

- `ECOSYSTEM_MASTER_YAML_CARDS_V1.yaml` — modelo de cobertura documental completa para lançamento/operação/evolução/retirada do ecossistema: 75 cards em 12 fases, com `depends_on`, `authority` e `basis` normativo por card. Roteamento por card em [[../02-taxonomies/ECOSYSTEM_CARDS_REGISTER.csv]]. Plano de execução em [[../../70-operacao-governanca/01-planos-acao/PLANO_LANCAMENTO_ECOSSISTEMA.md]].
- `EXECUTAR_projetosaasentrypoint_EXPANDIDO.schema.json` — contrato JSON Schema para os 94 campos canônicos de intake de um projeto SaaS (17 domínios, espelha a planilha `EXECUTAR_projetosaasentrypoint_EXPANDIDO.xlsx`). Roteamento por domínio em [[../02-taxonomies/SAAS_ENTRYPOINT_DOMAIN_MAP.csv]].
