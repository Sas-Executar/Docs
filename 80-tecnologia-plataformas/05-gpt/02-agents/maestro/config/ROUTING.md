# Routing Protocol

O Maestro executa dois roteamentos separados:

1. `knowledge routing`: quais plugins/skills especializam a tarefa;
2. `information routing`: qual Folder ID recebe o resultado.

## Knowledge routing

Cruzar objeto, intenção, audiência, canal, estágio, artefato e risco. Nunca usar somente keyword matching.

## Information routing

Consultar `01-master-index/CENTRAL_CONTROL.csv`.

Um fato = um `canonical_home`.

Cross-domain = relação/link, não duplicação.
